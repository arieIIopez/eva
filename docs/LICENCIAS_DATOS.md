# Licencias y procedencia de datos

La licencia Apache 2.0 de este repositorio se aplica al **software desarrollado para EVA**. No debe interpretarse como una relicencia automática de las bases de datos, cartografías, imágenes, marcas o insumos provenientes de terceros.

## Principio general

Cada capa publicada o reutilizada en EVA conserva las condiciones de uso, atribución y licencia que correspondan a su fuente original. Antes de redistribuir, adaptar o utilizar una capa fuera de EVA, la institución reutilizadora debe verificar esas condiciones directamente con la fuente responsable.

## Familias de información utilizadas por EVA

La versión actual integra información derivada o procesada a partir de fuentes públicas e institucionales, entre ellas:

- cartera de proyectos de la Red Metropolitana de Ciclovías y otras carteras territoriales;
- red ciclable existente;
- información censal y territorial;
- matrices y variables de origen–destino;
- siniestralidad vial;
- transporte público y estaciones;
- establecimientos de educación superior y matrícula;
- parques y áreas verdes;
- ferias y equipamientos urbanos;
- monumentos y elementos patrimoniales;
- límites comunales;
- variables derivadas para el modelo de elección modal.

La documentación metodológica y `docs/DATOS.md` describen el uso que EVA hace de estas capas, pero no sustituyen los términos de uso de cada fuente.

## Datos elaborados por el Gobierno Regional

Los resultados, transformaciones, indicadores y capas derivados que hayan sido elaborados íntegramente por el Gobierno Regional Metropolitano de Santiago deberán contar con una determinación institucional específica sobre su licencia de datos cuando corresponda. Mientras esa determinación no se encuentre expresamente indicada en el archivo o metadato de la capa, no debe asumirse que Apache 2.0 se aplica al contenido de `data/`.

## Software, documentación y activos institucionales

- El código fuente de EVA se distribuye bajo **Apache License 2.0**.
- La documentación propia del proyecto acompaña al software para fines de comprensión, auditoría y reutilización, salvo que un archivo indique una licencia distinta.
- Los logos, emblemas, marcas y demás elementos de identidad institucional del Gobierno Regional Metropolitano de Santiago están excluidos de la licencia Apache 2.0.

## Responsabilidad de una implementación reutilizada

Una institución que adapte EVA debe documentar, para cada nueva capa incorporada:

1. fuente y responsable;
2. fecha o versión;
3. licencia o condiciones de uso;
4. transformaciones aplicadas;
5. nivel de agregación;
6. restricciones de redistribución, si existen.

La publicación del código busca facilitar la transferencia institucional del método y del software, sin alterar los derechos existentes sobre datos de terceros.
