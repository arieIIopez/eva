# Replicabilidad de EVA

EVA separa conceptualmente cinco elementos: cartera de proyectos, red base, capas territoriales, criterios de evaluación y ponderaciones. Esta separación permite adaptar el sistema a otras carteras sin reproducir exactamente los datos de Santiago.

Una adaptación institucional requiere, como mínimo:

1. una red o condición base;
2. una cartera georreferenciada de proyectos candidatos;
3. fuentes territoriales y de movilidad pertinentes;
4. una definición explícita de criterios y parámetros;
5. un proceso institucional para discutir y sancionar ponderaciones.

El aspecto transferible de EVA no es el ranking particular de Santiago, sino el método para transformar una cartera territorial compleja en escenarios comparables, recalculables y trazables.

Las instituciones que reutilicen EVA deben revisar los supuestos metodológicos frente a su propio territorio y documentar cualquier modificación en datos, parámetros, criterios y pesos.
